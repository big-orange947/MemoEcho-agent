# 主控台委托任务真实闭环验证

本文用于验证主控台自然语言命令是否真正完成了“命令进入、解析联系人、创建任务、发起会话、工具执行、状态回写”的跨服务闭环。

## 关联标识

每次主控台命令都会生成一个 `executionId`。当前实现直接复用 Java 侧生成的 `commandId`，并写入桌面事件的 `rawPayload.executionId`。

同一个 `executionId` 会出现在以下日志中：

| 阶段 | 服务 | 关键日志阶段 |
| --- | --- | --- |
| 接收命令、投递 Runtime | Event Center（8093） | `command_received`、`event_dispatched` |
| 读取候选会话、联系人匹配 | Python Runtime（8000） | `candidate_load_completed`、`targets_resolved` |
| 编译和创建委托任务 | Python Runtime（8000） | `task_compiled`、`task_created` |
| 投递启动事件 | Python Runtime（8000） | `start_event_enqueued`、`start_event_started` |
| Agent 决策与工具调用 | Python Runtime（8000） | `task_action_decided`、`task_action_persisted` |
| 消息回写和任务状态更新 | Python Runtime（8000） | `reply_writeback_finished`、`task_runtime_updated` |

日志只保留 ID、数量、状态、路由和错误类型，不记录原始聊天正文、提示词、模型 API Key 或其他密钥。

## 启动顺序

1. 启动 QQ NapCat Connector（8091）。
2. 启动 Event Center（8093）。
3. 启动 Python Runtime：

```powershell
cd D:\project\memo_echo-agent\agent-runtime-python
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
```

4. 启动客户端并确认“服务已连接”。

## 闭环用例

在主控台输入：

```text
帮我和 km 约明天晚上七点打游戏
```

预期：

1. Event Center 输出同一 `executionId` 的 `command_received` 和 `event_dispatched`。
2. Runtime 输出联系人解析、任务创建和 `start_event_enqueued`。
3. Runtime 调用发送消息工具后输出 `task_action_persisted` 和 `reply_writeback_finished`。
4. 对方回复后，Runtime 使用同一任务 ID 更新进度；当 Agent 调用结束任务工具时，输出 `task_runtime_updated`。
5. 客户端的“委托任务”卡片会从进行中转为历史记录，并显示最终摘要。

Python：

```powershell

```

Java 编译：

```powershell
cd D:\project\memo_echo-agent\services-java\event-center-service
$env:JAVA_HOME = "D:\java"
$env:Path = "$env:JAVA_HOME\bin;$env:Path"

```

## 常见问题

| 现象 | 排查方向 |
| --- | --- |
| `Agent Runtime 当前未启用` | 确认 8000 端口可访问，并检查 Event Center 的 Runtime 地址配置。 |
| `targets_resolved` 为空 | 确认 NapCat 已登录，且联系人/群聊列表已成功同步。 |
| 有任务但没有启动事件 | 用任务 ID 和 `executionId` 搜索 `start_event_enqueued`；检查 Runtime 到 Event Center 的连接。 |
| 消息未发出 | 搜索 `task_action_persisted`、`reply_writeback_finished`，再检查 8091 的 NapCat 调用日志。 |
| 任务没有结束 | 搜索 `task_runtime_updated`，确认 Agent 是否真的调用了结束任务工具；主控台任务才允许 Agent 自主结束。 |
